# Teachable Machine 물병 모델 학습 가이드

시연에서는 물병이 **찌그러졌는지**를 판정해서, 차체·부품이 변형됐는지 판정하는 과정을 흉내 낸다.
예상 소요 시간은 약 20분이고, 14:00 전에 링크를 받는 것이 목표다.

---

## 0. 준비물
- 웹캠이 있는 노트북 (또는 휴대폰으로 찍은 사진)
- 물병 2~3개 (투명 페트병이면 좋다). 그중 1~2개는 찌그러뜨릴 용도
- 시연할 장소: 시연 때와 **같은 책상, 같은 조명**에서 찍는다

---

## 1. 프로젝트 만들기
1. https://teachablemachine.withgoogle.com 에 접속한다.
2. **시작하기(Get Started)** → **이미지 프로젝트(Image Project)** → **표준 이미지 모델(Standard image model)** 을 고른다.

## 2. 클래스 3개 만들기
클래스 이름은 **아래와 글자 하나까지 똑같이** 쓴다. 띄어쓰기도 같아야 한다. 앱이 이 이름으로 결과를 읽는다.

| 순서 | 기본 이름 | 바꿀 이름 |
|---|---|---|
| 1 | Class 1 | `정상` |
| 2 | Class 2 | `찌그러짐 의심` |
| 3 | (클래스 추가 클릭) | `판정불가` |

이름 옆 연필 아이콘을 누르면 이름을 바꿀 수 있다.

## 3. 사진 모으기 (클래스당 30~50장)
각 클래스에서 **웹캠(Webcam)** 을 누른 뒤 **길게 눌러 녹화(Hold to Record)** 를 누르고 있으면 연속으로 찍힌다.
휴대폰으로 찍은 사진이 있으면 **업로드(Upload)** 로 넣는다.

| 클래스 | 무엇을 찍나 | 요령 |
|---|---|---|
| `정상` | 멀쩡한 물병 | 세워서·눕혀서·돌려가며, 가까이·멀리, 라벨 앞면·뒷면 |
| `찌그러짐 의심` | 찌그러뜨린 물병 | 찌그러진 부분이 잘 보이게 여러 각도로. 살짝 찌그러진 것과 많이 찌그러진 것을 섞는다 |
| `판정불가` | 물병이 아닌 것 | 빈 책상, 손만, 다른 물건(펜·컵·휴대폰), 흔들린 사진, 너무 어두운 화면 |

꼭 지킬 것
- **물병을 화면 가운데에 둔다.** 모델은 사진의 가운데 정사각형만 본다.
- 클래스마다 **사진 수를 비슷하게** 맞춘다. 한쪽만 많으면 그쪽으로 치우친다.
- `정상`과 `찌그러짐 의심` 둘 다 **손으로 든 사진을 섞는다.** 그러지 않으면 모델이 "손이 있으면 찌그러짐"처럼 엉뚱하게 배운다.
- 배경과 조명은 시연 때와 같게 한다. 가능하면 물병 여러 개를 섞어 찍는다.

## 4. 학습하기
1. 가운데 **모델 학습시키기(Train Model)** 를 누른다. 고급 설정은 건드리지 않아도 된다.
2. 학습 중에는 **브라우저 탭을 바꾸지 않는다.** 탭을 바꾸면 학습이 멈출 수 있다. 보통 1~2분 걸린다.

## 5. 바로 테스트하기
오른쪽 **미리보기(Preview)** 창에 웹캠이 켜진다. 아래를 차례로 비춰 본다.

| 비출 것 | 기대 결과 |
|---|---|
| 멀쩡한 물병 | `정상` 막대가 가장 길다 |
| 찌그러진 물병 | `찌그러짐 의심` 막대가 가장 길다 |
| 빈 책상이나 손 | `판정불가` 막대가 가장 길다 |

틀리게 나오면 틀린 쪽 클래스에 사진을 10~20장 더 넣고 다시 학습한다. 2~3번 반복하면 대부분 잡힌다.

## 6. 링크 받기 (중요)
1. 오른쪽 위 **모델 내보내기(Export Model)** 를 누른다.
2. **Tensorflow.js** 탭에서 **업로드(공유 가능한 링크)** 가 선택된 상태로 **내 모델 업로드(Upload my model)** 를 누른다.
3. 잠시 후 아래 형태의 링크가 나온다. 복사한다.
   ```
   https://teachablemachine.withgoogle.com/models/XXXXXXXX/
   ```
4. 이 링크를 Claude에게 주면 3단계에서 `js/config.js`의 `TM_MODEL_URL`에 넣는다.
   - 이 링크는 비밀값이 아니다. 채팅에 붙여넣어도 된다.
   - 끝의 `/`까지 포함해서 복사한다.

## 7. 프로젝트 저장 (선택, 권장)
왼쪽 위 메뉴(≡) → **Google Drive에 저장** 또는 **프로젝트 파일 다운로드**를 누른다.
나중에 사진을 더 넣고 다시 학습할 때 처음부터 찍지 않아도 된다.
다시 학습한 뒤 **Upload my model** 을 다시 누르면 같은 링크에 새 모델이 올라간다.

---

## 문제 해결
| 증상 | 해결 |
|---|---|
| 웹캠이 안 켜짐 | 주소창 왼쪽 자물쇠 아이콘 → 카메라 **허용**. 다른 앱(Zoom 등)이 카메라를 쓰고 있으면 끈다 |
| 학습 버튼이 비활성 | 모든 클래스에 사진이 최소 몇 장씩 있어야 한다. 빈 클래스를 확인한다 |
| 미리보기에서 항상 한 클래스만 나옴 | 클래스별 사진 수 차이를 줄이고, 배경이 클래스마다 다르지 않은지 확인한다 |
| 시연 장소에서 정확도가 떨어짐 | 시연 장소에서 사진을 20장씩 더 찍어 다시 학습하고, 다시 업로드한다 |

## 시연할 때 팁
- 앱에서 사진을 올릴 때도 **물병을 가운데에** 두고 찍는다.
- AI 결과는 참고용이다. 앱은 판정을 자동으로 바꾸지 않고 "불량으로 표시" 제안 버튼만 보여준다. 발표 때 이 점을 강조한다.
